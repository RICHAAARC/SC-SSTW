# 局部支持内判别方向控制：真实 MULTI V1

本轮沿“管状块状态编码＋真实MULTI生成轨迹写入＋盲状态路径恢复”推进。上轮真实 LOWBAND16 原生终态排名59/21、DIRECT107/127、RAW42051/36、MP460/82；重复载荷9/9零误码，未形成时间同步闭环。旧OLD8有原生终态及DIRECT的1/1正证据，但RAW420/MP4仍失败。具体来源及独立核验保存在20261003T122227915210Z同次结果审计。

本轮只有一个方法变化：在真实MULTI每一步，约束pilot原始梯度在原active支持内的公开联合判别方向，再使用原整体shrink-only cap。它检验截断前方向分配是否有助于形成终态和媒体中的时间状态证据。原始更新显著截断与旧未masked判别分量偏小只是动机，不构成因果证明；旧载体同样含较多空间外能量而仍能终态成功。

## 固定同次对照

四臂为OFF、PAYLOAD_MULTI、STATE_LOWBAND_MULTI、STATE_CONTRAST_MULTI。前三臂沿用原LOWBAND控制函数；原失败LOWBAND作为同次对照。四臂共享来源、种子、初始张量及pristine scheduler，各用独立fresh copy，分别完成50个真实原生采样步骤，水印作用于25–49步。第25步控制前的latent、history、条件与无条件分支记录一致性指纹。

全部writer使用原四个16×16支持、32个局部余弦列、RM32／45状态／4年龄、5568active／192边界零、channel4、alpha=1/sqrt5568、eta696、pilot cap1及原重复payload。原OLD8仍作为独立公开receiver读取全部臂，不按writer标签择优。旧OLD8写端的历史正证据保留，后续按结果分支复用。

## 公开方向空间与实际控制

令mu_i为原公开R44有限族中全部174条有效路径的模板，mu_0为第一条公开有效候选；锚点不由观测或答案选择。D是44窗口的相邻差分算子。M为原pilot_active在R44的掩码，共5440 active与192 boundary坐标；第45窗另外128 active。

联合空间预先定义为：

    S = span{ M(mu_i-mu_0), M D^T D(mu_i-mu_0) : 全部174条公开有效候选 }

先作用M，再做FP64薄SVD正交化。数值秩容差为eps64×max(generator.shape)×最大奇异值；该容差只用于线性代数，不是检测阈值。当前正确/错误密钥的独立CPU构造秩均为214。完整谱、正交/跨度/支持残差、配方hash和实际basis单独保留；原未masked空间的130秩及百分比不能替代本次受限构造。

每次原始pilot仍由原条件clean投影的active系数MSE梯度乘eta696得到。只将其R44部分投影到S，使用原局部basis重建；第45窗保持原始物理raw增量，然后整体应用原cap1。cap只缩小，不将低于上限的更新放大。第45窗截断前相同，截断后的实际更新可以随整体scale变化。

对任何原active支持内的方向r，r−P_S r与所有当前ABS/DIFF候选成本差方向正交。因此投影在截断前保留全部候选相对成本的一阶且精确线性变化，同时欧氏范数不增加。这个固定观测模型下的性质支持方向分配假设，但真实后续生成与VAE/媒体是另一层验证，不能据此预判成功。

控制空间只接收公开协议与密钥。真实攻击位置、后验真实路径、错误赢家、消息答案及任何观测都不参与空间构造。原生生成每一步真实执行控制，终态不追加修正，也不使用VAE/媒体STE。

## 诊断与盲接收

100份写端侧车继续保存实际conditional_clean、pilot_delta、z_pre、z_post、cfg_clean投影。两状态臂共50份方向诊断保留raw／precap／actual三方向对两种评分全部174候选的相对效应，共52200个数值。原LOW raw/precap由实际投影除原cap_scale代数重建，明确标记FP32舍入和非独立原始张量观测；新臂分别保存实际梯度投影、投影后方向和最终施加增量的重读投影。

每步记录原始/受限raw范数、cap_scale、row45与支持闭合情况；每臂汇总实际pilot、payload、merged范数的和、平方和及最大值。相同上限不意味着实际能量相同。原始MSE及其降低只作为诊断。

每臂一次真实VAE解码/clamp和原RGB8量化保存；同一份持久化raster分别进入DIRECT_RGB8、原RAW420、原MP4保存读取，12次VAE重编码。三个通道的颜色转换和元数据可能不同，不将差异单独归因于H264。每通道/key只读一次payload，与两个receiver family数量无关。

正式盲接收只取接收媒体形成的潜变量、密钥和公开协议，保留原g0/R44、ABS/DIFF、完整候选、局部状态/边响应、整数等价类、tie和拒绝语义。两个公开family分别在每个臂、每个通道、两个密钥上读取，不能事后合并或择优。原生终态另有完整公开候选诊断，只是writer posthoc；其文件、调用和计数与主接收分开。主接收及终态各自的raw快照先封存，再加入真值后评；所有acceptance仍为false。

## 预定后续分支

若当前新臂在原生终态仍不能形成正确路径证据，停止继续修补这一LOWBAND16构造，回到已有终态与DIRECT正证据的OLD8。若终态形成而RAW420／MP4仍失败，才进入载体通道存留验证。若MP4获得可复现的正确路径优势，再进入相位、起点与状态路径联合盲恢复，以及真实时间编辑验证。本notebook只执行当前固定比较，不自动启动下一分支，也不以单次结果宣称可复现或总体成功。

后续频带对照应核对本项目成功载荷的实际频率定义、覆盖和冗余；固定块大小、码本、MULTI控制与预算后，仅改频率位置，与本轮方向验证分开。不能仅凭高/低频名称排除中高频。图像或整段重复载荷的压缩成功不能直接证明局部时间状态成功。

后续完整方法仍需位置相关载荷分片／交织、去重与纠错，以及截取、删帧／重复、速度变化下的片段和序列判定。按用户明确边界，本轮不重试二元导频＋DP修复；未来编码先排除声明编辑范围内的结构歧义。当前g0/R44完整候选核验仍有其有限范围，重复载荷零误码不依赖路径，不能证明同步后载荷恢复闭环。
