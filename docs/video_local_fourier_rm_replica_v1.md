# OLD8 局部时间状态的双空间副本：首轮固定验证

本轮沿用户采纳的“局部时间状态 → 同窗空间冗余 → MP4后软合并 → 状态空间同步 → 时间相关载荷”路线推进。当前交付只检验前两项能否在真实通道中形成可区分的时间证据；不将重复载荷读取或执行完整性当作后续链路已完成。

依据为已复核的固定来源：OLD8正确密钥ABS/DIFF真路径在DIRECT排名1/1，RAW420为3/2，MP4为22/30。频率审计确认OLD8已包含成功全局载荷映射到8×8的四个中心；成功载荷还伴随不同的空间支持、冗余和实际更新量。停止LOWBAND16与CONTRAST同类修补，本轮不改频率或状态码。

## 固定载体与写入

组A保留原局部支持，组B统一横移8个潜空间采样点：

| 逻辑块 | A：行半开区间、列半开区间 | B：行半开区间、列半开区间 |
| --- | --- | --- |
| 0 | [8,16), [12,20) | [8,16), [20,28) |
| 1 | [8,16), [44,52) | [8,16), [52,60) |
| 2 | [28,36), [12,20) | [28,36), [20,28) |
| 3 | [28,36), [44,52) | [28,36), [52,60) |

八块互不重叠，空间位置在观测前固定，不作搜索。B的逻辑块i与A共享原U_i、key域、符号和列顺序，不能把新空间块号作为新hash输入。仍在潜变量channel4、45个规则窗口、4年龄、32逻辑chip上工作；空间支持从该通道平面10%变为20%，不是视频像素覆盖率。VAE可以混合各支持的影响，不能宣称两个副本独立。

四臂固定为OFF、PAYLOAD_MULTI、STATE_OLD_MULTI、STATE_REPLICA_MULTI。原前三臂数值算法原样复用，共享同来源、种子、初始张量、各自fresh原生scheduler。每臂50步，非OFF仅第25–49步执行控制，共200原生步骤、75载荷控制和50状态控制。第25步控制前记录latent/history/conditional/unconditional指纹，保留所有步与失败。

## 目标、梯度与预算

原OLD8全45窗目标有5568个active坐标，alpha=1/sqrt5568、目标物理L2为1。双副本分别以alpha/sqrt2为目标，共11136 active和384 boundary；由于各基正交且支持不重叠，联合目标物理L2仍为1。

联合损失为两组全部active残差平方的均值，eta=1392=2×696，故名义2eta/N仍为0.25。这只是抵消mean分母加倍，不能由eta数值推断实际更新增强；随后的范数匹配会消去正的整体标量。

先完成同次STATE_OLD_MULTI，封存其第25–49步实际施加的physical pilot L2，记为b_s。新臂保留自己的联合梯度方向r_s，执行：

    delta_s = (b_s / ||r_s||_2) r_s

匹配覆盖全部45窗口及两个空间组，不只看接收R44投影。允许scale大于1；它是明确的配对范数匹配，不伪称沿用原shrink-only cap。b_s=0时施加零增量；若r_s=0而b_s>0，保留失败，不注入epsilon方向或任意补偿。baseline预算记录缺失时保留相应失败，不能悄悄换成cap1预算。预算读取仅发生在写端，本轮因此是同次配对控制实验，不是独立部署写端证明。

每步保存实际组A/B能量、联合物理范数、目标范数、scale和FP32匹配残差；目标各半不代表实际组间能量各半。匹配指状态pilot的每步实际L2，不是最终输出距离或两个完整生成轨迹等价。载荷算法不改，但随生成轨迹不同，实际payload更新可以变化；payload、pilot、merged分别记录，不能宣称跨臂merged总预算完全匹配。原CFG倍率和后续真实采样保持不变。

固定总能量下，两个副本不保证提高信噪比；理想独立等方差噪声也不能自动提供净优势。本轮检验实际空间分布及通道存留下的效果。

## 盲接收与保留证据

每个接收潜变量和key提取一次A/B逐窗口组响应，明确保留接收窗口索引、空间支持和可用掩码。两个公开协议对全部四臂、三个通道和两种key固定执行：

- OLD8使用A的原投影及原alpha模板。
- REPLICA8先将A/B原投影各乘sqrt2，再等权平均，恢复到原alpha模板坐标。权重和尺度在观测前固定，不使用writer arm、budget、真实消息、真实路径或组表现。
- 同窗同逻辑槽合并，不跨接收时间平均；合并支持为两组支持交集，不在缺失时按组质量选择或临时改权重。
- 保留raw_groups、scaled_groups、合并q、逐组掩码及交集掩码；缺失支持不能冒充零值观测。

预定方法比较是STATE_OLD_MULTI的OLD8读出与STATE_REPLICA_MULTI的REPLICA8读出；全部交叉读出仍保留，不能看到结果后更换主接收协议。ABS与DIFF分别报告，不通过事后择优模式宣称方法完成。

两个协议继续使用原ABS/DIFF评分、g0/R44、174条合法路径、3915个目录槽、固定整数模板等价类与tie规则。不增加路径惩罚、不事后扩充歧义集合。协议输出、模式和重叠窗口不是独立来源样本；不在结果后择优合并两个协议。

每臂真实VAE解码一次并保存单份RGB8，同一raster分别形成DIRECT_RGB8、RAW420和MP4，之后各自真实重编码。颜色转换及元数据仍可能不同，RAW420与MP4差异不能单独归因于H264。载荷每通道/key只读一次，与接收协议数无关。

写端100份侧车保存实际张量投影。原生terminal另作完整候选诊断，文件与调用分母独立；它不能作为主盲接收输入。主接收和终态诊断各自先封存快照，再进行真值后评。配对预算、写端潜变量和生成记录均不进入盲接收函数。
