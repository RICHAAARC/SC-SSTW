GROW remains a concrete implementation source rather than the umbrella method name: the [author repository](https://github.com/luopengchen/GROW), retained implementation commit `6aa69a9c5d4a9e75df457fcca8dfc71b64a6b870`, and the [CVPR 2026 paper](https://openaccess.thecvf.com/content/CVPR2026/papers/Luo_GROW_Watermark_Generation_with_Progressive_Guidance_for_Diffusion_Models_CVPR_2026_paper.pdf) remain attributed. Main retains GROW's complete original native sampler/decoder/media path unchanged.

The reports and immutable source identities are linked in [the evidence index](mechanism_evidence_index.md). Earlier whitelist records remain separate original-version executions. Conditional joint V1 has its own same-version original-source audit at ac111d0; this main integration does not rerun models/media or relabel that evidence as a new main execution. CPU arithmetic/interface equivalence and portable engineering checks support release integration only.

Payload uses keyed FFT coordinates over the full 40×64 latent spatial extent, not spatial patch-local payload. GROW keeps its full 46-time reader. The stable temporal receiver uses unchanged FFT2 real/ortho, t1:R+1, channels0..3, time-major bit::8 and Counter first-encounter ties; strict zero maps to a negative vote. The inherited `video_trajectory_payload_gt_v1` runtime filename now exposes only this length adapter, not GT or temporal smoothing methods.

Sync uses 4-frame × 4×4 spatial patches and original age slices (including the final source180 normalization). The H0/H1 receiver uses 885 frame/displacement cells and 709 paths per read. H1 wins are not detections; adjacent k paths differ at one frame. Previous-frame insertion restores a nominal index grid, not missing RGB. C/D truth is allowed in preparation, but never enters the blind selector/correction. Oracle maps are parsed after blind payload sealing; message semantics only after oracle sealing. Source/config byte hashes may be read early for identity. Complete-map aliases and failed cache entries remain recorded without retry. In the attribution research candidate, non181 action contrast is local rather than the global score gap: 177 averages per-frame q advantages only where source maps differ, and 89 compares Q[b]=sum(observed_frames*q)/89 across every top path and every different-action path. Same-action top ties resolve only the action and retain absolute-path ambiguity.

The retained Stage1 authorization counterexample remains: at source ab60d45… / run 20261007T122708953536Z, the 177 protocol had positives 2/2 and one null ACCEPT among six; the 89 protocol had positives 2/2 and no null ACCEPT, but all six nulls were UNCERTAIN. Presence/no-watermark, wrong-key rejection, uncertainty/erasure, broader dynamic edits and population FPR remain unfinished. Spatial-local payload and state-dependent segment encoding are gaps relative to original goals, not automatically adopted new work. The fixed same-version case already reports joint recovery, six quality rows and edit costs; independent-source applicability, broader attacks, payload-off quality cost and generalization remain unestablished. Mechanism closure is reported to the user before discussing paper experiments; paper scripts/test sets/chart templates/large comparisons are not being prepared.

The attribution research candidate keeps source/condition/view truth in its experiment protocol helper; its blind seals use opaque observation/query IDs, public N, RGB identity/shape and key identity, and posthoc joins happen only after a complete 64-row decision seal. Per-observation read/encode failures retain both key slots, continue remaining observations, and make aggregates unresolved unless another row already proves a false claim. Main core has no runtime/experiment/governance imports; runtime has no experiment imports. The three saved-input CLIs and the fixed conditional-joint CLI work without notebooks/scripts. Source provenance uses the actual runtime manifest in a no-Git directory and only inspects Git if root/.git exists, never an unrelated parent. Config and manifest identities are evidence, not model inputs or method thresholds.
