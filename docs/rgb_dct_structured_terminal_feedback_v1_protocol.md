# RGB-DCT structured terminal feedback V1: fixed development protocol

Frozen before the ten-slot GPU run. This is a **development set** on the two unchanged B2 sources, `eval_copperkettle_s2501` (seed 2026092501) and `eval_paperplane_s2502` (seed 2026092502), using the exact B2 prompts and model/media settings. Source, key, 181 frames, 30 RGB-DCT groups, `C=sum(q_g>0)`, and `C>=24:H1` are unchanged. Only saved and read-back MP4 RGB24 determines H0/H1. All float RGB and quantized RGB8 scores are diagnostic. Success can only motivate a separately frozen new-source evaluation.

The fixed arms per source are OFF, original SINGLE49, ONLY49, MULTI46_47_48_49, and MULTI46_47_48_FREE49. The last is an ablation, not a pass gate. There is no T46 admission gate. All ten slots (1810 frames) persist before generation; failures, missing MP4s, rejected updates, and worker timeout keep their slots. Two sources run serially in fresh processes. No GPU run is authorized for implementation.

## Distinct mechanism and construction

The old Flow-Tube terminal feedback/objective alignment uses a detached terminal-latent hinge and native single-direction response probe. RGB-DCT A/B1/B2 uses a full VAE gradient. GROW single-step Jacobian is an autograd step-30 Jacobian, not terminal RGB-DCT group response. This route uses no gradient: an explicit positive RGB-DCT carrier is deterministic-VAE encoded against the OFF float RGB, then split into **three fixed latent temporal bins** `1:15`, `15:30`, and `30:45` (Python half-open indices); endpoints `0,45` remain zero. Each bin is normalized to unit support RMS. Empty bins remain zero method outcomes. The same basis, defined once from OFF, is used at all control points; no result selects a bin. This modest 3D basis is a construction choice to make full-tail finite response affordable while spanning early, middle, and late latent time.

At each included native step, freeze current latent, CFG velocity and **complete** UniPC history. For each of the three basis directions, make one small positive velocity probe and independently advance a copied history through the genuine no-grad CFG/UniPC tail to step 50. Decode all four terminal latents (current baseline and three probes) with the frozen FP32 VAE and measure their full 30-group float RGB `q`. Form `J[:,j]=(q_probe_j-q_base)/measured_probe_immediate_rms_j`. No analytic identity transport and no mixing probe histories into the main history. The exact three-bin carrier lift is fixed from OFF VAE encodes; each bin is normalized to unit RMS over the **full 44-frame latent support**. Probe responses use current-state native dynamics.

At each point solve a deterministic regularized 3D nonnegative coefficient problem over the fixed candidate lattice `{0, 1/4, 1/2, 3/4, 1}` times each remaining radius, with `sum_j a_j <= remaining_radius` as a conservative **predicted L1 domain**. The separate measured native RMS is the binding physical budget. The objective is `mean_g w_g*max(m-q_pred_g,0)^2 + lambda*||a||_2^2`, with `m=1e-4`, `lambda=1e-4`, and `w_g=4` for a baseline-positive group and `1` otherwise. Ties choose lexicographically smallest coefficient tuple. This grid is a bounded numerical solution, not adaptive experiment selection; 125 predictions require no model calls. At most three fixed scales `{1,1/2,1/4}` of the selected nonzero tuple are terminal-verified in order. After each candidate, decode the true tail and accept only if (1) no baseline-positive `q_g>0` becomes nonpositive, (2) the true weighted hinge (without coefficient regularizer, which is prediction-only) decreases by at least `1e-8`, and (3) all immediate and cumulative budgets hold. The first passing scale is accepted. No passing scale means zero update, a valid method result; the main latent and history then take the baseline step. An accepted update uses its own **first-step** scheduler result/history, never the forecast terminal history, for the next control point. Positive-group protection is measured on the true float terminal against the current arm's same-history baseline. The same safeguard applies at every point.

## Frozen radius, probe, and budget

`R*=0.042943312697648145` is an upper bound on the **sum** of measured native immediate support RMS values. Each point may spend at most the **remaining** `R*`; ONLY49 and MULTI can therefore reach the same total cap, although their actual expenditure need not match. The probe velocity perturbation is fixed as `-R*/8 * basis_j / sigma_i`; its **actual** native immediate RMS is measured from the same probe rollout and is the finite-difference denominator for J. A zero immediate response leaves that column zero, forces its coefficient to zero, and is recorded as a method outcome. There is no extra calibration call. Each candidate uses a nonnegative combination of probe perturbations scaled by `a_j / measured_probe_rms_j`; its actual native immediate RMS, not its coefficient norm, is charged to the ledger. Any candidate above the remaining-total cap is recorded with a budget rejection reason before terminal decoding. The **single-step** response peak absolute value must be `<=0.25`, and the cumulative terminal latent difference from the same-run OFF `z50` must be finite; no hard terminal RMS gate is used. The ledger separately reports sum of immediate RMS, sum of squared immediate RMS, maximum single-step immediate peak, maximum peak of the running sum of accepted immediate response tensors (a descriptive same-shape ledger, not a physical state), final terminal delta RMS and final terminal delta peak versus OFF. These are not described as equivalent energy. The design uses a cap rather than forcing full `R*` because B2's fixed full-strength gradient lost positive groups on both sources.

ONLY49 controls only step 49. MULTI46_47_48_49 controls in order 46,47,48,49. FREE49 controls 46,47,48 then takes original free step 49. All three share the same OFF-based carrier basis. At a point, the baseline/probes and each verified candidate are recomputed from that arm's **current** state and a copied scheduler; no arm borrows another arm's state. The controlled main trajectory continues from the accepted copy. SINGLE49 preserves B2's original positive-carrier deterministic VAE lift, native unit-response probe and fixed exact `R*` target.

## Fixed computation bound per source

OFF: 100 transformer forwards and 50 scheduler steps. SINGLE49: 1 unit-response probe and 1 applied native step. Each feedback point: one baseline tail, three probe tails, and at most three candidate tails. A tail beginning at index `i` uses `2*(49-i)` transformer forwards and `50-i` scheduler steps after the known current CFG velocity. At four points `i=46..49`, this is at most `7*(6+4+2+0)=84` transformer forwards and `7*(4+3+2+1)=70` scheduler steps. The three-step ablation has at most `7*(6+4+2)=84` transformer forwards and `7*(4+3+2)=63` scheduler steps, plus its final free T49 step. ONLY49 has zero tail transformer forwards and at most 7 scheduler steps. At each point a baseline and three probes plus at most three candidates require at most seven FP32 VAE decodes, or `7*(4+3+1)=56` for the three feedback arms combined. OFF and SINGLE49 add two decodes; final media for the three feedback arms adds three more, for 61 total. Basis construction uses two deterministic VAE encodes, with no backward/VJP. An allowance of 16 transformer forwards per source covers explicit main-point CFG velocity recomputation. Thus conservative per-source maxima: 300 transformer forwards (`100+84+84+16=284`, rounded up), 193 scheduler steps (`50+2+70+63+1+7`), 61 VAE decodes, two VAE encodes, zero backward calls. For both sources: 600 transformer forwards, 386 scheduler steps, 122 decodes, four encodes. Every attempted/completed forward, scheduler step, VAE encode/decode, MP4 save/read and receiver call is logged; the implementation must not exceed its config caps. Transformer and VAE run in separate GPU residency phases, with state/probe latents held on CPU between phases; the phase switch count and elapsed time are recorded.

The per-source worker timeout is fixed at 28,800 seconds (eight hours). It accommodates up to 61 full 181-frame FP32 VAE decodes plus repeated model residency switches; the B2 three-decode wall time is not a valid timing estimate for this route. Timeout is recorded as a resource failure, with the partial JSON and all ten planned slots retained. The three candidate tails at a point are computed together before the VAE phase, then decoded in fixed scale order; after the first accepted candidate, later computed tails are marked `TAIL_COMPUTED_NOT_SCORED_AFTER_ACCEPT` and their native calls remain in the ledger.

There are at most 66 in-memory receiver scores per source: 56 point baseline/probe/candidate float scores and two layers for each of five final arms. These are counted separately from five MP4 receiver scores. At each computed tail, nonfinite state/history is engineering invalid; scored tails additionally require finite full `q`. Exact zero probe is a method result. The actual accepted first-step `z` and UniPC history fingerprints are checked at commit. Recomputed next-point terminal fingerprints and float `q` differences are retained as diagnostics; small cross-phase numerical differences do not reject an otherwise valid arm. Each point uses its freshly measured same-history baseline for group protection.

B2's two OFF development-source median `|q|` values were approximately 0.000712 and 0.00352, so the fixed `1e-4` margin sits below those observed scales. The `R*/8` probe and `R*` cap are predefined from the original SINGLE49 response scale; neither is chosen from this new run. This is a mechanism construction, with no new visual-quality threshold or automatic GPU result gate.

Every point record persists before/after each phase: baseline `q`/objective, all probe `q`/immediate responses and J, predicted `q`/objective, all true candidate `q`/objective, positive-group gained/lost indices, coefficient tuple, scale, native budget ledger, history fingerprints, forward counters, acceptance or rejection reason. Each arm's final float RGB, RGB8 and MP4 groups and quality diagnostics persist independently. Worker termination preserves its partial JSON and converts remaining slots to explicit missing/invalid states. Normal reject is not engineering invalidity.
