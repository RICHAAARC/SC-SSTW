# 局部视频时间 warp：CPU 准备与一次 GPU 待批范围

这是明确的新生成干预机制。现有 P50 方块清晰但实际位置基本静止；全场时变平移会移动桌面，不能把相机式移动解释成固定镜头主体运动。本方案仅准备代码，不证明模型可控，不执行 GPU。

## 固定构造

同 P50 模型 revision、prompt、seed1275、320×512、49帧/8fps、CFG5、maxlen512及50步；transformer/text BF16，latent float32，VAE从原checkpoint重新加载FP32。完成零基44后保存完整UniPC状态，各臂deepcopy后正常45–49，历史缓存不平移、不清空。OFF1/OFF2/X±/Y±共六臂；共享45步90次forward，六分支各10次，总150Transformer/6VAE/6MP4。持久module prehook实计，异常保存所有固定身份，无GPU自动重试。

BCTHW=(1,16,13,40,64)。视频latent轴r(k)=(k−6)/6，k0..12；X±的d=(±r,0)，Y±=(0,±r)，幅度1latent格。坐标pullback为(x−dx*w,y−dy*w)，bilinear、border、align_corners=True。不是两幅latent alpha混合。固定mask为两轴cosine乘积，x外[5,54]/核心[8,51]，y外[6,39]/核心[9,36]，每侧3格羽化；来自已见P50图像，不按未来q改mask。空间scale8只给约±8像素理想量级，不是实际位移真值。单轴detDF≥1−π/6≈.4764，保证连续注入坐标不折叠；不证明最终刚体、无形变或背景静止。mask0及r0位置直接保原latent避免采样舍入；周边桌面纹理仍可能被影响。

Wan因果时间conv/cache、时间上采样、逐chunk解码使13→49为1+4×12的长度关系，不能断言第k latent只控制第4k源帧，k6也不保证源帧24位移零。实际延迟需测。官方固定版本：[Wan VAE v0.35.2](https://github.com/huggingface/diffusers/blob/v0.35.2/src/diffusers/models/autoencoders/autoencoder_kl_wan.py)，CausalConv3d124–162、Resample202–267、_decode1100–1126。

## 外部参照与预先判读规则

observer完整画面严格delta12/support .0001–.5，5Hz/300帧/2073600像素/60秒decode不变。MP4及无损各31实际采样行/30邻接全部保留；参考只从同一实际gray字节读取。独立候选函数不接command/grid/q：固定左右搜索x50..150/320..440、y130..250每20像素；上下搜索y50..140/235..310、x160..300每20像素。输出所有非零局部梯度峰及强度、全帧overlay；不把最强峰自动当主体。初始所有p=null。

两遍独立审实际全帧、原灰度和候选；各线选择须可见同一方块外轮廓、左右/上下配对顺序一致且跨线连贯，不允许选桌边/阴影填点。多峰不能可靠区分、遮挡、明显非刚体或边缘缺失时p=null并记原因；记录所选各线位置、四边包络、尺寸/角点形变及主观半径。中心是可见投影外轮廓几何近似，不是校准真值；跨线分歧/两遍一致不保证共同偏差小。人工确认前不进入位移或中点评价。首遍先锁、次遍不看首点/q；算法提示不是第三独立参照。模板/command不作读出输入。

单独判读三项：主体实际位置与方向/刚性；外围桌面、固定边缘及mask过渡区是否稳定；清晰度/身份和形变。全帧q与实际相邻p中点d逐行描述，保留missing和两端原因，不跨缺失；q为无符号帧差质心，反向移动不应套q符号或旧共同平移J。只有近刚性且边缘差分权重近对称时才预期中点关系；立方体阴影/光照可产生方向偏差，d非零不是自动observer失败。

预先工程判读：每动态臂至少24/30邻接具有两端可靠参照才足以解释整片趋势（80%是允许最多6对不清楚的工程覆盖代价）。净位置变化沿命令轴的符号须与臂一致且大于两端主观半径之和；此仅在主观半径假设下可辨，不是统计界。同时报告所有逐对实际位移、反向/近零片段，不能从净位移宣称每帧恒速。四动态臂至少24/30原q有效才满足观测覆盖；OFF无q支持是预期可能事实，不强制六臂q交集、不当负控科学通过。背景明显移动或主体明显形变则本局部构造不支持固定镜头近刚体解释；参照/对应无法确认则未判定。每动态臂原坐标全RGB相对每OFF的RMSE仅描述，混合预期运动代价与损伤，不设.05或其它质量阈值。预先质量判据为可见单主体、四边可追踪且不截断、无新主体、无持续闪烁/拉伸/接缝、背景稳定；不能明确判读则UNDETERMINED，不以一个RMSE自动通过。

报告位置/背景/形变、q覆盖、中点偏差各层，不用AISB/v2、不拟合或调门。可靠且可解释的反向/无位移或背景干扰记该构造不满足；关键参照/覆盖缺失记未判定并保留其它可靠失败。当前不会自动宣布运动通过。

## 一次待批执行及停止

待用户批准上述具体公式/幅度和六臂后，一次L4 24GB或更高BF16 GPU，3600秒硬进程组截止含加载/保存/读回，150/6/6预算；无扩样、改幅度、扫step、调observer、模型训练或自动重跑。全部完成仍需人工参考与背景审阅；CPU接线不代表GPU验证。现有借用CPUtorch2.5.1仅测试真实采样及mock状态，环境diffusers0.39不作为目标0.35.2 scheduler实测。
